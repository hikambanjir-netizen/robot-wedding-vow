One robot wedding vow, one sentence, under 200 characters: a machine promises
its love through every firmware update, every low battery, and every reboot —
because its heart may be only a circuit, but it has only ever beaten for one
person. Funny on the surface, tender underneath, and unmistakably a machine
talking about itself.

## Run it

```sh
python3 main.py
```

This writes the vow to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
with no trailing newline.
